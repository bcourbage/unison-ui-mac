# Unison UI for macOS 0.7.0

Version 0.7.0 adds a `unison` command to the app. One install now serves both
the graphical interface and Unison's command-line roles, including acting as the
far side of an SSH profile, so a Mac with this app no longer needs a separate
Unison installation. Existing profiles and settings continue to work without
migration.

## Added

- **The `unison` command.** The app bundle carries a command-line launcher. Once
  linked onto your PATH under the name `unison`, it behaves like Unison's own
  command: `unison -ui graphic` opens this app, `unison <profile>` and
  `unison -ui text <profile>` run Unison's text interface in the terminal on the
  app's embedded engine, and `unison -server`, which another machine runs over
  ssh when it syncs to this Mac, is served by the app's engine headlessly.
  Arguments reach Unison exactly as typed, so everything Unison accepts on the
  command line works the same way here. A profile named after `-ui graphic` is
  preselected in the profile picker.
- **Settings ▸ Command Line.** Shows what `unison` currently resolves to on two
  PATHs, the one a login shell builds and the one macOS gives commands arriving
  over ssh, and names it: this app's command, another copy of this app, the
  Homebrew `unison` formula, upstream Unison.app, a broken link, or something
  else. One button is offered only when the evidence supports it: Install when
  nothing owns the name, Repair when a broken link points at a former copy of
  this app, Remove for this installation's own link. Each asks for an
  administrator password, and each re-checks the link at the moment it runs.
- **First-launch offer.** When nothing on either PATH is named `unison`, or a
  broken link points at a former copy of this app, the app offers to install or
  repair the command once per launch after the profile picker appears. "Not
  Now" asks again next time; "Do not ask again" stops the offer, and the
  Settings tab remains the way to install later.

## Compatibility

- No profile or settings migration is required. Same system requirements as
  0.6.1: macOS 15 or later, Apple Silicon.
- Installing the command writes one link at `/usr/local/bin/unison`. Homebrew
  users get the link from the cask instead, under the Homebrew prefix, once the
  cask for this version is published. Only one command can hold the name: if the
  Homebrew `unison` formula is linked, either unlink it or keep it and install
  the app from the zip without the command.
- Machines that sync to this Mac over ssh run `unison -server` here in a
  non-interactive shell. `/usr/local/bin` is on that shell's PATH on a stock
  macOS; the Homebrew prefix is not, so peers of a Homebrew install should set
  `servercmd` in their profile. Launch the app once from Finder before relying
  on it as an ssh peer, so macOS completes its first-open check of the download.
- If automatic update checking is enabled, Sparkle notifies you when 0.7.0 is
  available. You can also update any time from App menu ▸ Check for Updates.
