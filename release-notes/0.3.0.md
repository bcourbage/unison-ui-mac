# Unison-UI-Mac 0.3.0

Version 0.3.0 is a major reliability and data-integrity update. It substantially improves remote-connection handling, recovery from stalled operations, profile editing, reconciliation performance, and diagnostic privacy.

Existing profiles and settings continue to work without migration.

## Connection reliability and recovery

- **SSH failures are reported as connection failures.** If a remote connection drops during sign-in (for example, after the SSH login grace period expires), Unison returns to the profile list and shows one clear error. It no longer presents the failure as another password request and then remains stuck on “Opening…”.

- **Slow local scans are distinguished from remote stalls.** A lengthy local scan, including a first-run macOS permission request for locations such as the Photos Library, is no longer treated as evidence that the remote connection has failed. A confirmed remote stall still produces a clear recovery prompt.

- **The no-progress transfer notice is advisory.** Large transfers can have long intervals without visible progress, particularly when processing many small files or active database files. The app now explains that the transfer may still be running, clears the notice when progress resumes, and does not incorrectly declare the connection lost.

- **Restart-required errors are presented consistently.** When the embedded engine cannot safely continue, one dialog appears on the active window with a direct option to quit.

- **Remote connections close and reopen more reliably.** Connection teardown now drains residual engine work before reuse, preventing failures during an in-process reconnect. App-owned SSH transport children are also explicitly retired during connection close and application shutdown.

## Profiles and data integrity

- **Profile editing preserves custom configuration.** Comments, include/source directives, and configuration lines the form editor does not directly manage are retained instead of being silently discarded.

- **Profile saves and renames are transactional.** New content is staged safely, backups are handled without destroying an existing backup prematurely, and failures leave the profile in a coherent, retryable state.

- **Revert restores Unison’s actual recommendation.** Reverting a selected row now asks the engine to restore its original recommendation rather than attempting to reconstruct it from the displayed direction.

- **Archive cleanup is more conservative.** “Clean Stale Archives” follows included profile files when it can resolve them reliably and leaves uncertain archive entries unchecked.

- **Large reconciliations complete more responsively.** Completion results are delivered together, eliminating the repeated engine round trips that could make a large reconciliation appear frozen.

- **Profile-wide maintenance reports partial failures accurately.** Operations now distinguish complete success, partial success, failure, and cases where no change was needed.

## Diagnostics and privacy

- The crash-report helper no longer claims that macOS crash reports contain no personal data. It identifies potentially sensitive contents (including account names, file paths, process arguments, and system details) and retains the review step before a report is shared.

- Dynamic diagnostic values are private by default in macOS Unified Logging.

## Compatibility

- Requires macOS 15 or later on Apple Silicon.
- Embeds Unison 2.54.0. Remote systems should use a compatible Unison 2.54.x release.
- Existing profiles and application settings require no migration.

## Known limitations

- Returning to the profile list is not yet reliably available while a connection is still opening. If a credential dialog is present, use Cancel; otherwise, wait for the connection result or quit the app.

- The no-progress transfer notice is informational. A quiet interval alone cannot prove that a remote transport has failed.

- A genuinely wedged embedded engine cannot yet be interrupted safely in place. When the app reports that a restart is required, quit and reopen the profile.
