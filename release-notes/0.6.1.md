# Unison UI for macOS 0.6.1

Version 0.6.1 is a small user-interface and update-infrastructure release on top
of 0.6.0. Existing profiles and settings continue to work without migration.

## Fixed

- **The reconcile toolbar no longer shifts between phases.** After a scan
  finished, the Go button used to move to where another control had been, because
  a single button was relabelled and resized per phase. The toolbar is now
  spatially stable: every button keeps its position, so Go stays where you expect
  it.

## Changed

- **Stop is a sync-only control.** The Stop button keeps its "Stop" label and its
  position in every phase, and is active (red) only while a synchronization is
  running, when it aborts that sync. During a connect or scan it is inactive. To
  return to the profile list at any time, including during a scan, use Profiles
  (or ⌘⇧P); leaving during a scan does not cancel it, the scan winds down in the
  background. Rescan is disabled while a scan or sync is already running.
- **Update checks now go through `updates.courbage.net`.** Builds from 0.6.1
  onward check for updates through a small privacy-scoped proxy rather than
  contacting GitHub Pages directly. It serves the same signed appcast
  byte-for-byte, so update integrity is unchanged and a signed feed is still
  required. What the proxy records, and what it deliberately does not, is
  described in the Privacy section of the FAQ on the product website.

## Compatibility

- No profile or settings migration is required. Same system requirements as 0.6.0:
  macOS 15 or later, Apple Silicon.
- The move to `updates.courbage.net` takes effect for update checks made by this
  build and later. A 0.6.0 install discovers 0.6.1 through its existing feed; once
  0.6.1 is installed, its later checks use the new address.
- If automatic update checking is enabled, Sparkle notifies you when 0.6.1 is
  available; whether it then downloads and installs automatically or only after
  you confirm depends on the separate automatic-download choice from the
  first-launch prompt. You can also update any time from App menu ▸ Check for
  Updates.
