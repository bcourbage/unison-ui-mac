# Unison-UI-Mac 0.5.1

Version 0.5.1 is a safety and documentation release on top of 0.5.0. Its main
change is how the app behaves when you leave a profile while it is still
scanning. Existing profiles and settings continue to work without migration.

## Changed

- **Leaving during a scan returns to the profile list without cancelling the
  scan.** While a scan is running, the toolbar's Stop control is **Return to
  Profiles**: it takes you back to the profile list but does not stop the scan
  itself, which finishes in the background. There is no in-place "stop the scan"
  action. If a remote scan hangs, quit and relaunch the app.

## Fixed

- **File-integrity safeguard for interrupted scans.** Earlier builds could, in
  some cases, interrupt a running scan and then keep using the same
  synchronization engine. Because that engine's internal state could not be
  verified after a forced interruption, the app no longer does this — protecting
  your files and Unison's archives is the priority. Ordinary **Sync Stop** (during
  an actual file transfer) is unchanged and fully supported.
- Corrected the built-in **Manual** and the README so they accurately describe
  the current behavior — the Settings tabs and menus, the SSH version check and
  compatibility boundary, and how the app updates itself.

## Security

- **Credential prompts default to masked entry.** When SSH asks for a password,
  key passphrase, or verification code, the app now always shows a masked
  (secure) field; only the exact host-key "are you sure you want to continue
  connecting (yes/no)?" question uses a plain field. A prompt that merely
  mentions "authenticity" or `yes/no`, or a host-key line immediately followed by
  a password prompt, is treated as a secret and masked — where an earlier build
  could have shown it in a plain, readable field.

## If you are still on 0.5.0

Until you have updated to 0.5.1: if a remote scan hangs, **quit and relaunch**
rather than using Stop Scan followed by Rescan.

## Compatibility

- No profile or settings migration is required. Same system requirements as 0.5.0
  (macOS 15 or later, Apple Silicon).
- If automatic update *checking* is enabled, Sparkle notifies you when 0.5.1 is
  available; whether the download and install then happen automatically or only
  after you confirm depends on the separate automatic-download choice from the
  first-launch prompt. You can also update any time from App menu ▸ Check for
  Updates.
