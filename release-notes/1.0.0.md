# Unison UI for macOS 1.0.0

Unison UI for macOS reaches 1.0 with safer profile management, clearer diagnostics,
and a more polished interface, from creating your first profile to reviewing
differences and recovering from errors.

Existing profiles and settings continue to work without migration. Requires macOS 15
or later on Apple Silicon.

## Fixed

Deleting a profile now protects synchronization history that other profiles share.
Profiles that use the same pair of roots share archive files, and deleting one of
them could remove those archives, after which the other profile would forget earlier
deletions and could copy a deleted file back. The app now recognizes shared
archives, keeps them, and names the profile that uses them. It checks again under
the archive lock before it moves anything, and it keeps the archives whenever it
cannot tell whether another profile uses them. Reset Archives likewise names the
other profiles whose synchronization history it will also reset.

## Changed

**Warnings and errors.** Warnings and failures now lead with a concise summary. The
complete diagnostic sits in a scrolling, selectable Details area with a Copy Details
button, so long paths stay intact. Warnings offer Continue and Cancel, and restart
notices say what to do next.

**Profile setup.**

- An empty Profiles window offers a Create Profile… button, or a Manage Profiles…
  button when every profile is hidden.
- Run is enabled only while a profile is selected, and long profile names keep their
  beginning and end, with the full name in a tooltip.
- A settings search with no matches offers a Clear Search button.
- Profile names are checked as you type, with the reason shown when a name is not
  valid.
- Check Remote Command is unavailable for a profile that has not been saved yet, and
  the editor says why.

**Diff window.** The Diff window now names the file being reviewed and, when it can
identify them reliably, shows the two files being compared. The full command stays
one click away behind a Command… button. For a standalone standard `diff` command,
the result reads "Differences found." instead of "Exited with status 1". Custom
commands and pipelines keep the status they reported.

**Finishing touches.** The reconcile summary uses correct singular wording, help
examples display as code, and Archive Maintenance explains what it can clean up.
Long Command Line setup paths are truncated in the middle, with the full path in a
tooltip.
