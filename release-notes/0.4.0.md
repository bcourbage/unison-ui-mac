# Unison-UI-Mac 0.4.0

Version 0.4.0 adds the ability to stop a scan that is in progress, and fixes profile navigation during connection setup. It builds on the 0.3.0 reliability release.

Existing profiles and settings continue to work without migration.

## Stopping a scan

- **You can now stop a scan in progress.** Once a scan is waiting on the remote side, "Stop Scan" (in the Action menu and the toolbar) interrupts it. The app tears down the connection cleanly and waits for the engine to settle; the reconciliation window then stays open showing "Scan stopped," and Rescan starts fresh on that same clean connection. (Before the scan reaches that point, or for connections the app cannot stop in place, "Return to Profiles" takes you back to the profile list instead.)

- **Scope.** Stopping in place applies to a direct SSH connection after the scan has reached the point of waiting for the remote side. Connections that use SSH multiplexing (ControlMaster), a proxy (ProxyCommand / ProxyJump), or a custom SSH command use Return to Profiles instead of stopping in place. A long local scan is not stopped in place either: you can Return to Profiles while it finishes in the background, and if the engine is genuinely stuck you can quit. A confirmed remote stall still produces a clear recovery prompt.

## Profiles and navigation

- **Returning to the profile list stays available while connecting.** "Show Profile Picker" and the toolbar's Profiles control are no longer intermittently disabled while a connection is being established, so you can always get back to the profile list.

## Compatibility

- No profile or settings migration is required. Same system requirements as 0.3.0.
