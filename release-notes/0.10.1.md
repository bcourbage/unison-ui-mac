# Unison UI for macOS 0.10.1

Version 0.10.1 is a maintenance release. It stops the bundled command-line tool
and sync engine from leaving coverage files behind, and it adds an offline copy
of this app's user manual to the Help menu. Existing profiles and settings
continue to work without migration.

## Fixed

- **Release builds no longer leave `.profraw` files behind.** Earlier builds
  carried code-coverage instrumentation that wrote a `default.profraw` file to the
  working directory when the bundled `unison` command or its `-server` role exited,
  including on Macs used as synchronization peers. That instrumentation is removed
  from release builds, and the release pipeline now checks the shipped binaries to
  keep it out.
- **Help opens an offline user manual.** Help now opens a copy of this app's user
  manual bundled with the app, so it works without an internet connection and always
  matches the version you are running. It includes the corrected command-line
  session documentation. The separate upstream Unison reference manual is unchanged.
