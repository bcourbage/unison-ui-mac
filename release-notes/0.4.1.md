# Unison-UI-Mac 0.4.1

Version 0.4.1 is a small fix release on top of 0.4.0. It removes a duplicate password prompt that could appear when signing in to a password-based SSH profile.

Existing profiles and settings continue to work without migration.

## Fixed

- **No more duplicate password prompt after a failed attempt.** On a profile that signs in with an SSH password, entering a wrong password used to make the app ask for the password an extra time, so you had to type the correct one twice. Now a wrong password brings up a single "Permission denied, please try again." prompt, and the correct password there signs you in.

## Compatibility

- No profile or settings migration is required. Same system requirements as 0.4.0.
