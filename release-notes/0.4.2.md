# Unison-UI-Mac 0.4.2

Version 0.4.2 adds a native app icon that adapts to the system appearance and
makes folder sizes and sync progress easier to read at a glance. It builds on
0.4.1.

Existing profiles and settings continue to work without migration.

## Added

- **A native app icon with light, dark, and tinted variants.** On macOS 26 and
  later the icon matches the system appearance (light, dark, or tinted) everywhere
  it appears: Finder, the Dock, and the About panel. On macOS 15 and earlier it
  shows the light version.
- **Folder rows now show the total size of their changes.** Every folder in the
  file list reports the combined size of the changed items inside it, so you can
  see how large a pending sync is without opening each folder. Folders whose only
  changes are deletions or property updates stay blank.

## Changed

- **Folders show sync progress, even when expanded.** While a sync runs, a
  folder's progress bar fills in step with everything inside it. Expanded folders
  now show this bar next to each item's own progress, not just collapsed ones. A
  folder that is itself a change and also holds changes can be expanded, and its
  own row stays selectable.

## Compatibility

- No profile or settings migration is required. Same system requirements as 0.4.1
  (macOS 15 or later).
