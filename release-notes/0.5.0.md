# Unison-UI-Mac 0.5.0

Version 0.5.0 adds in-app updates, so the app can find and install new versions
on its own, and moves distribution to a Developer ID-signed, notarized build. It
also adds a Software Updates settings tab and a Donate menu item. It builds on
0.4.2.

Existing profiles and settings continue to work without migration.

## Added

- **In-app updates.** The app can now check for updates and install them itself,
  through the Sparkle update framework. Use App menu ▸ Check for Updates at any
  time. On first launch the app asks whether to check automatically.
- **Software Updates settings.** A new Updates tab in Settings lets you change
  these choices at any time: whether the app checks for updates automatically,
  and whether it includes an anonymous system profile when it checks.
- **Donate menu item.** Help ▸ Donate opens the project's GitHub Sponsors page.

## Changed

- **Signed and notarized distribution.** The app is now distributed as a
  Developer ID-signed, notarized build, so it opens with a normal double-click.
  Updates after the first install come through the app itself.

## Compatibility

- No profile or settings migration is required. Same system requirements as 0.4.2
  (macOS 15 or later, Apple Silicon).
- If you installed an earlier version by hand, install 0.5.0 once (via Homebrew or
  the download); after that the app updates itself, automatically if you enable
  automatic checks or any time from App menu ▸ Check for Updates.
