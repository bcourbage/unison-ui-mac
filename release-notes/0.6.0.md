# Unison UI for macOS 0.6.0

Version 0.6.0 is a safety, correctness, and robustness release on top of 0.5.1.
Existing profiles and settings continue to work without migration.

## Safety

- **Archive maintenance is crash-safe.** Clean Stale Archives, Reset Archives,
  and archive recovery now run as a single locked transaction: they take the
  same per-archive lock a live Unison uses, stage everything, and only then move
  the removed set to the Trash as one unit. Before the removal is committed, any
  failure rolls back the staged files; a crash is detected on the next launch and
  recovered — restoring the files if it had not yet committed, or finishing the
  removal if the whole set was already committed — with the locks released only
  after you confirm no other Unison is running.
- **Clean Stale Archives only offers provably superseded copies.** Orphans,
  "probably old" copies, anything involving a remote replica, and any archive
  whose roots can't be read unambiguously are now shown for reference only, never
  selectable and never preselected.
- **The manual installer (`install.sh`) is safer.** It installs atomically, so a
  failed install can never leave you without a working app, verifies that the
  download quarantine was actually cleared, and accepts only a Release build.
  (Homebrew-cask installs are unaffected.)
- **Fixed a rare crash or corrupted results at the end of a sync**, caused by
  values in the end-of-sync snapshot moving under the garbage collector before
  they were read.
- **"Rescan Ignoring Archives…" can no longer overlap in-flight work.** It runs
  only from a ready state, so it can't start on top of a connection, scan, or
  sync already in progress.

## Fixed

- **Editing a profile preserves a symlinked `.prf`.** Saving no longer replaces a
  symlinked profile (for example one linked from a dotfiles repository) with a
  regular file, and it keeps the file's comments, ordering, and escaping intact.
- **A profile the app can't read is protected.** An unreadable or non-UTF-8 `.prf`
  is not opened as an editable empty form, so a Save can't overwrite it with a
  blank profile.
- **Diffing a file no longer freezes the reconcile window.** The window stays
  responsive while a diff runs; a stalled diff is reported, and other engine
  actions stay disabled until it returns. If it never does, quit and reopen the
  app.
- **Ignore and Diff act on the item you mean** — the selection from the menu bar,
  the clicked row from the right-click menu — and **Select Conflicts** now reveals
  conflicts hidden inside collapsed folders.
- **No false version warning from an SSH login banner.** The remote Unison-version
  check reads Unison's own version line, so a login banner that mentions a version
  number no longer triggers a spurious compatibility warning.

## Changed

- **Genuinely built for macOS 15.** The app and its embedded Unison engine are now
  compiled for the macOS 15 minimum and verified on macOS 15 before release.

## Compatibility

- No profile or settings migration is required. Same system requirements as 0.5.1:
  macOS 15 or later, Apple Silicon.
- If automatic update *checking* is enabled, Sparkle notifies you when 0.6.0 is
  available; whether it then downloads and installs automatically or only after
  you confirm depends on the separate automatic-download choice from the
  first-launch prompt. You can also update any time from App menu ▸ Check for
  Updates.
